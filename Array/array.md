# 📊 Массивы (6 задач)
Массивы, префиксные суммы, скользящее окно и однопроходные алгоритмы.

## 🟢 Уровень 1: Разминка и базовые паттерны

### 4. Найти сумму единичек
**Теги:** `#массивы` `#один-проход`
**Условие:** Дан массив целых чисел, необходимо написать метод, который найдет максимальное количество идущих подряд 1 в массиве.
**Что требуется:** Один проход, O(1) памяти.
**Где ошибаются:** Обработка null/пустого массива; сброс счётчика на нуле.

### 6. Удалить нули из вектора
**Теги:** `#массивы` `#два-указателя` `#inplace`
**Условие:** Дан вектор, надо удалить из него нули, сохранив порядок остальных элементов. (Для языков типа Java/Python: "перенести нули в конец массива").
**Что требуется:** Решение за O(n) времени и O(1) памяти. Без использования квадратичных сдвигов.
**Где ошибаются:** Решение за O(N^2) здесь не ОК.

## 🟡 Уровень 2: Золотой стандарт собеседований

### 2. Найти максимальный по длине строго монотонный подотрезок массива
**Теги:** `#массивы` `#один-проход`
**Условие:** Дан массив чисел. Необходимо найти монотонный подотрезок (то есть строго убывающий или строго возрастающий) максимальной длины и вернуть пару индексов его начала и конца.
**Примеры:** `[2, 7, 5, 4, 4, 3]` → `{1, 3}` (подотрезок `[7, 5, 4]`).
**Что требуется:** Решение за линейное время и константу дополнительной памяти (менять входной массив нельзя).
**Где ошибаются:** Большинство кандидатов ошибаются на плоских участках `a[i] == a[i+1]`, неправильно обрывая или продолжая последовательность.

### 1. Подотрезок с суммой Х
**Теги:** `#префиксные-суммы` `#хэш-таблица`
**Условие:** Дан массив целых чисел, нужно найти непустой подотрезок (непрерывную подпоследовательность) с заданной суммой Х, либо сказать, что это невозможно. Выдать индексы его концов.
**Что требуется:** Hash map с префиксными суммами, решение за O(n).
**Где ошибаются:** Забывают, что в массиве могут быть отрицательные числа; подотрезок должен быть непустой; забывают, что подотрезок может включать самый первый элемент (частичная сумма равна Х).

### 3. Максимальный подмассив единиц
**Теги:** `#скользящее-окно` `#массивы`
**Условие:** Дан непустой массив из нулей и единиц. Нужно определить, какой максимальный по длине подынтервал единиц можно получить, удалив (пропустив) ровно один элемент массива. Вернуть 0, если такого подынтервала не существует. Удалять один элемент обязательно.
**Примеры:** `maxones({1, 1, 1, 1, 1}) == 4` (обязательно удаляем один элемент).
**Что требуется:** В один проход накапливаем длины последних двух последовательностей, разделенных нулем, на основании этого обновляем максимум. O(1) памяти, O(N) времени.
**Где ошибаются:** Краевой случай: массив из всех единиц (не удалять элемент нельзя); последовательность единиц длиннее, чем две другие последовательности, разделённые нулём.

## 🔴 Уровень 3: Продвинутые паттерны

### 5. Разделить массив на подмассивы минимальной стоимости
**Теги:** `#массивы` `#жадность` `#один-проход`
**Условие:** Дан массив целых чисел `nums` длины n. Стоимость массива равна значению его первого элемента. Нужно разделить массив на 3 непрерывных непересекающихся подмассива. Вернуть минимальную из возможных сумм стоимостей этих трех подмассивов.
**Пример:** `min_cost([10, 3, 1, 1])` → `12` (разделение: `[10, 3]`, `[1]`, `[1]`, стоимость: `10 + 1 + 1`).
**Что требуется:** Задача о поиске двух минимальных элементов в массиве, содержащем все элементы, кроме первого. Решение за O(n) за один проход.
**Где ошибаются:** Решение за O(n^2) или через сортировку O(n log n) не принимается.
