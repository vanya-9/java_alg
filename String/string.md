# 🧵 Строки (15 задач)
Парсинг, преобразования и обработка строк.

## 🟢 Уровень 1: Разминка и базовые паттерны

### 15. Исключить символ из строки и получить палиндром
**Теги:** `#строки` `#два-указателя`
**Условие:** На входе дана непустая строка. Требуется выяснить, можно ли удалить из нее ровно один символ так, чтобы получился палиндром.
**Примеры:** 
- `"aaab"` → `true` (можно удалить последний символ)
- `"xyz"` → `false` (нельзя превратить в палиндром удалением одного символа)
**Что требуется:** Решение за линейное время с константой дополнительной памяти. Хорошим бонусом будет отсутствие лишней копипасты при проверке двух случаев (пропустить левый / пропустить правый символ).
**Где ошибаются:** Лишняя копипаста при проверке двух случаев.

### 13. Реализовать функцию fuzzysearch
**Теги:** `#строки` `#подпоследовательность` `#два-указателя`
**Условие:** Реализовать функцию нечёткого поиска (approximate string matching). По факту требуется проверить, является ли первая строка подпоследовательностью второй.
**Примеры:** 
- `fuzzysearch('car', 'cartwheel')` → `true`
- `fuzzysearch('cwhee', 'cartwheel')` → `true`
- `fuzzysearch('cwheeel', 'cartwheel')` → `false`
**Что требуется:** Реализация функции с использованием только одного прохода по символам строки, без использования regexp.
**Где ошибаются:** Тянут regexp вместо простого однопроходного сканирования; не уточняют краевые тест-кейсы (пустая строка, регистр, подстрока, не начинающаяся на ту же букву).

### 12. Нормализация пробелов
**Теги:** `#строки` `#два-указателя` `#inplace`
**Условие:** Заменить последовательности пробелов в строке на одиночные пробелы. Считается, что строка mutable (или передается изменяемый массив с символами).
**Пример:** `normalize("some  string")` → `"some string"`
**Что требуется:** Простой in-place алгоритм с двумя указателями. O(n) по времени, O(1) по памяти.
**Где ошибаются:** Забывают изменить размер строки; неправильно обрабатываются пробелы в конце/начале строки; падение на пустой строке.

### 2. URL-кодирование
**Теги:** `#строки` `#два-указателя` `#inplace`
**Условие:** Написать метод, который заменит все пробелы в строке на `"%20"` inplace. На вход подается строка с зарезервированными под расширение символами.
**Что требуется:** Два прохода по строке. На первом считаем кол-во пробелов и итоговую длину. На втором идём с конца и копируем символы, кодируя в процессе пробелы. O(1) по памяти, O(N) по времени.
**Где ошибаются:** Пытаются копировать слева направо и затирают ещё не обработанные символы.

## 🟡 Уровень 2: Золотой стандарт собеседований

### 4. Изменения порядка слов в строке без изменения положения пробелов
**Теги:** `#строки` `#два-указателя`
**Условие:** Написать функцию, которая меняет порядок слов в строке на противоположный, при этом не меняя расположение пробелов. 
**Пример:** `hello_my__dear_world__` → `_world_dear___my_hello_` (где `_` это пробел).
**Что требуется:** Максимально простой работающий код, учитывающий нюансы вроде пустой строки, строки только из пробелов или строки без пробелов.
**Где ошибаются:** Смещают пробелы; падают на краевых случаях.

### 14. Сжатие строки (RLE)
**Теги:** `#строки` `#один-проход`
**Условие:** Дана строка, состоящая из букв A-Z. Нужно написать функцию RLE, которая на выходе даст строку вида `"4A3B2C"`. К каждому символу добавляется количество его повторений (сперва количество, затем сам символ). Сгенерировать ошибку, если на вход пришла невалидная строка.
**Что требуется:** Один проход по строке; корректный вывод последней группы.
**Где ошибаются:** Забыли проверить наличие одного символа; забыли вывод последней группы; забыли сгенерировать ошибку на невалидном входе.

### 10. Проверка строк на исправление (OneEditApart)
**Теги:** `#строки` `#два-указателя`
**Условие:** Реализовать функцию, проверяющую, можно ли одну строку получить из другой не более, чем за одно исправление (удаление, добавление, изменение символа).
**Примеры:** `OneEditApart("cat", "cut")` → `true`; `OneEditApart("cat", "acts")` → `false`.
**Что требуется:** Решение за O(n) времени и с O(1) доп. памяти.
**Где ошибаются:** Дублируют логику для веток «длиннее / короче»; неверная обработка разной длины строк.

### 6. Количество подстрок без повторов символов
**Теги:** `#строки` `#скользящее-окно` `#хэш-таблица`
**Условие:** Дана строка символов. Найти количество пар индексов i и j (i <= j), между которыми, включительно, нет повторяющихся символов.
**Пример:** Для строки `"aba"` ответ 5: `[0,0]`("a"), `[0,1]`("ab"), `[1,1]`("b"), `[1,2]`("ba"), `[2,2]`("a").
**Что требуется:** Решение за O(N) по времени, O(|Alphabet|) по памяти. Один проход с запоминанием последней виденной позиции символа.
**Где ошибаются:** Используется последняя виденная позиция для текущего символа, а не самая правая позиция последнего повторяющегося символа. В строке `"baab"` подстрока `"aab"` будет ошибочно считаться не имеющей повторов.

### 7. Поиск подстроки в строке без учета порядка букв
**Теги:** `#строки` `#скользящее-окно` `#хэш-таблица`
**Условие:** Дан текст T и строка S. Требуется найти подстроку S' в T такую, что она совпадает с S с точностью до перестановки букв. Вернуть индекс первого вхождения или -1.
**Что требуется:** Решение за O(|T|), где константа не должна зависеть от размера алфавита. Представление строки в виде хэш-таблицы с диффом частот между S и текущим окном.
**Где ошибаются:** Пересчитывают всё окно каждый шаг (лишний множитель |Sigma|), не удерживают дифф частот.

### 9. Удалить смайлики вида ":-)" и ":-(" из сообщения
**Теги:** `#строки` `#автомат` `#один-проход`
**Условие:** Удалить из сообщений смайлики, подпадающие под регулярку `:-\)+|:-\(+` за линейное время. Специально обрабатывать вложенные смайлики нельзя (так, `:-:-)))(((` должно превратиться в `:-(((`, но не в пустую строку).
**Что требуется:** Однопроходный алгоритм а-ля поддержание состояния автомата (например, текущей длины заматчившегося смайлика).
**Где ошибаются:** Массивные реализации автомата; неправильная обработка того, "что и когда писать в выход".

## 🔴 Уровень 3: Продвинутый парсинг и окна

### 5. Восстановить IP-адрес(а)
**Теги:** `#строки` `#бэктрекинг`
**Условие:** Дана строка из цифр. Восстановить все возможные варианты IPv4-адресов, которые при удалении точек дали бы эту строку.
**Что требуется:** Решение с бэктрэкингом.
**Где ошибаются:** Ведущие нули (`01`), октеты > 255, неверная длина строки.

### 1. Разворачивание скобочной грамматики в строку
**Теги:** `#строки` `#стек` `#рекурсия` `#парсинг`
**Условие:** Дана скобочная грамматика: в круглых скобках записано выражение, следом за ними идут квадратные скобки с неотрицательным целым числом. Разворачивается в виде конкатенации строки в круглых скобках на саму себя N раз. Также есть правило конкатенации термов.
**Примеры:** `"(ab)[3]"` → `"ababab"`, `"((ab)[2])[2]"` → `"abababab"`, `"(a)[2](b)[2]"` → `"aabb"`.
**Что требуется:** Аккуратное решение со стеком либо рекурсией. Можно сперва разделить выражение на конкатенацию термов, потом вычислить значение каждого.
**Где ошибаются:** Выход за границы строки при разборе; остаются куски грамматики в выводе; некорректно парсится число в квадратных скобках, если имеет более одного разряда.

### 11. Сумма hex-чисел
**Теги:** `#строки` `#арифметика`
**Условие:** Даны две строки, каждая из которых — hex-число в прямой записи (старший знак в нулевой позиции). Написать код суммирования этих чисел.
**Пример:** `sum("fed", "13") == "1000"`
**Что требуется:** Сложение столбиком.
**Где ошибаются:** Ошибки на кейсах `FF + FF` или `FFFFF + 1`.

### 8. Кратчайшее расстояние между элементами (X и Y)
**Теги:** `#строки` `#один-проход`
**Условие:** Дана строка, состоящая из букв 'X', 'Y' и 'O'. Необходимо найти кратчайшее расстояние между буквами 'X' и 'Y', либо вывести 0, если 'X' либо 'Y' отсутствуют. Дистанция между двумя рядом стоящими буквами считается как 1.
**Примеры:** `"YOX"` → `2`, `"000X0OYOXO"` → `2`, `"XX"` → `0`.
**Что требуется:** Один проход по массиву с запоминанием последних встреченных позиций X и Y и текущего кратчайшего расстояния.
**Где ошибаются:** Учитывают только одно направление; не обрабатывают отсутствие одной из букв.

### 3. Длинное умножение на разряд
**Теги:** `#строки` `#арифметика` `#inplace`
**Условие:** Дана строка из десятичных цифр (длинное число, младшие разряды расположены по младшему индексу). Написать код, который умножит это число на число 1 <= n <= 9.
**Что требуется:** O(1) дополнительной памяти, т.е. надо использовать исходную строку.
**Где ошибаются:** Перенос (carry) на последнем разряде, забытый финальный перенос.
